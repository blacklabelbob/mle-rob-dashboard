    [heading_3] What is a Knowledge Base
    [paragraph] The knowledge base is the central resource that fuels AI agents - everything you want the agent to know, including training resources and information, lives in the knowledge base.  Before building a knowledge base, consider the type of agent (voice vs. conversation), the agent's specific purpose or goal, and whether you have adequate training resources available.   It's important to keep knowledge bases specific to each agent's function rather than creating one knowledge base for multiple different agent types. 
    [heading_3] Knowledge Base Features
    [paragraph] Web Crawler
    [bulleted_list_item] Crawls web pages and stores information inside High Level 
    [bulleted_list_item] Can crawl any website, funnel, or document with a URL, including Google Docs and spreadsheets 
    [bulleted_list_item] Auto-refresh feature allows daily, weekly, or monthly recrawling of resources 
    [bulleted_list_item] Particularly useful for ever-changing documents or training resources 
    [paragraph] FAQs
    [bulleted_list_item] FAQs are prioritized by the bot when searching for information - they represent the "golden standard" for responses  
    [bulleted_list_item] Can be created manually or automatically through conversation optimization 
    [bulleted_list_item] When you use thumbs down on a bot response in Conversation AI, you can modify the answer and save it as an FAQ 
    [bulleted_list_item] If both a file upload and an FAQ address the same topic, the FAQ will generally take priority 
    [paragraph] Tables
    [bulleted_list_item] Tables hosted natively in the platform allow faster information extraction than external spreadsheets 
    [bulleted_list_item] Useful for structured data like exhibitor information, speaker lists, or navigation details  
    [bulleted_list_item] Import tables as CSV files, similar to importing contacts 
    [paragraph] Rich Text
    [bulleted_list_item] Allows building documents directly in High Level rather than linking to Google Docs 
    [bulleted_list_item] Provides standard rich text formatting options (links, fonts, bold, italics, etc.) 
    [bulleted_list_item] Native hosting enables faster bot information retrieval 
    [paragraph] File Uploads
    [bulleted_list_item] Currently supports PDFs, docs, and doc X files 
    [bulleted_list_item] Some file types not commonly requested by customers may not be supported 
    [heading_3] Adding Knowledge Bases to Agents
    [paragraph] Agents can have up to seven knowledge bases attached.  Access this in AI Agents > Knowledge Base > Bot Training. The recommendation is to create individual knowledge bases for different services or topics rather than one large knowledge base, as this prevents the bot from getting confused or crossing threads.   Multiple knowledge bases appear as tabs in the interface for easy viewing. 
    [heading_3] Testing & Optimization
    [paragraph] Knowledge Chunks Feature
    [paragraph] The knowledge chunks feature is critical for optimization - click the star button next to any bot response to see where the information came from, what prompt and intent were used, and the chat history.    This allows you to identify which specific resource provided the answer and make targeted adjustments. 
    [paragraph] Editing Crawled Content
    [paragraph] You can directly edit stored crawled information by clicking the edit button on any crawled page.  Note that if auto-refresh is enabled, manual edits will eventually be overwritten.  For permanent changes, update the source document before the next crawl cycle. 
    [paragraph] Testing Recommendations
    [bulleted_list_item] For Conversation AI, test by having text conversations directly in the interface 
    [bulleted_list_item] For Voice AI, use the web call function in the test agent box 
    [bulleted_list_item] Focus testing on specific use cases and questions rather than general conversation 
    [bulleted_list_item] Testing sessions may be limited to 10 minutes per day 
    [heading_3] Q&A Session Highlights
    [paragraph] Gatekeeper and Transfer Control
    [paragraph] Participant asked about preventing voice AI from transferring calls before properly qualifying leads. Robert recommended using the flow builder in Conversation AI for more control over multi-step processes and branching logic, while voice AI would require extensive prompt engineering through ChatGPT or Gemini.   
    [paragraph] Multiple Knowledge Base Selection
    [paragraph] For scenarios where different knowledge bases should be used based on conversation context (e.g., investor vs. homebuyer), use prompting to instruct the bot which knowledge base to reference in specific situations.  
    [paragraph] Image Support
    [paragraph] Currently, Conversation AI can receive and interpret images but cannot send images directly back to clients.  It can send links to images.  The AI router node coming in Agent Studio may enable image generation and sharing in the future.  Consider submitting feature requests for native image repository access from knowledge bases.  
    [paragraph] Course Content Integration
    [paragraph] Request made to allow course videos, transcripts, and lesson materials to be automatically accessible to knowledge bases without duplicate uploads.   Recommendation is to submit this in the AI ideas board with comprehensive naming conventions for better searchability.
