- **Rep-usable on a live call tomorrow** — run it on the discovery call; whatever it says, the Phase One conversation has started.

**Recommendation:** lead the new AI Visibility Check push into **med spas** (fastest emotional "oh no" + cash to spend + nobody's optimized) and **home services** (roofing/HVAC — Rob's beachhead, acute pain). One tool serves all six.

## The bigger vision this seeds — the Crawford EDP→PVP automation engine

Rob's north-star idea: feed it a website (later the Second Brain), and it runs the entire Cannonball pipeline automatically — EDP discovery, free-tool searches, multi-source joins, PVP generation, and outreach emails — sellable to any B2B we work with.

**The AI Visibility Check is Module 1 of that engine** (the AEO EDP: "is AI recommending you?"). The roadmap:
- **M1 · AI Visibility (done)** — the AEO existential data point + PVP.
- **M2 · Site teardown** — Firecrawl the prospect's site → conversion + AEO + schema + speed gaps → scored report (reuse geo-seo-claude scoring).
- **M3 · The joins** — cross-reference public records + the referral-edge engine (already designed, `REFERRAL-DISCOVERY-ENGINE.md`) to surface who could refer them.
- **M4 · PVP + outbound** — generate the permissionless value asset + the exact PEA outreach email, ready to send (n8n).
- **M5 · Second Brain hook** — once a client's Everything Agent exists, feed it in for depth.
Built on tools already owned: OpenAI/Claude, Firecrawl, Supabase, n8n. Each module is also a standalone lead magnet.
